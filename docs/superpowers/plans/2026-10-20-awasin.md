# Awasin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web app (PWA) yang memprediksi risiko asap karhutla, banjir/hujan ekstrem, dan angin/cuaca ekstrem per sekolah, menerima laporan lapangan yang dicocokkan dengan prediksi, dan menjalankan mode darurat (pengumuman, papan tugas, absen kesehatan).

**Architecture:** Next.js di Vercel melayani halaman dan route API. Supabase menyimpan data, auth, dan foto. Tiap jam pg_cron memanggil `/api/cron/refresh`, yang mengambil data NASA FIRMS + Open-Meteo, menghitung level per sekolah per jam, menyimpan `forecasts` dan `school_status`, mengirim notifikasi, dan menyalakan mode darurat. Semua logika keputusan berupa fungsi murni di `src/risk`, `src/reports`, `src/notify`, sehingga bisa dites tanpa jaringan.

**Tech Stack:** Next.js 15 (App Router, TypeScript), @supabase/supabase-js + @supabase/ssr, Supabase Postgres (RLS, pg_cron, pg_net, Vault, Storage), leaflet + react-leaflet (tile OSM), web-push, Vitest. Tidak ada dependency lain tanpa alasan tertulis.

**Spec:** `docs/spec.md`

## Global Constraints

- Rp 0, tanpa kartu kredit. Hanya Vercel Hobby, Supabase Free, NASA FIRMS MAP_KEY, Open-Meteo tanpa key, Telegram Bot API, web push VAPID.
- Jangan pakai Vercel cron. Refresh per jam lewat pg_cron + pg_net (`0 * * * *`).
- Setiap tabel baru wajib punya `grant` eksplisit + RLS (aturan Supabase untuk project baru sejak 2026-05-30).
- Auth memakai email + password, akun dibuat lewat seed. Jangan pakai magic link: SMTP bawaan Supabase dibatasi beberapa email per jam.
- Wilayah: Kalimantan Tengah, 20–30 sekolah di `supabase/seed.sql`.
- Semua waktu disimpan dalam UTC (`timestamptz`) dan ditampilkan sebagai WIB (`Asia/Jakarta`). Tanggal absen = tanggal WIB.
- Atribusi wajib tampil di peta dan halaman sekolah: `Weather data by Open-Meteo.com` (link), `Fire data: NASA FIRMS`, `© OpenStreetMap contributors`.
- Foto laporan ≤ 200 KB, sisi terpanjang ≤ 1280 px, dikompres di browser.
- Teks UI dalam bahasa Indonesia. Label aksi persis:
  `normal` "Masuk normal" · `kurangi_luar` "Kurangi kegiatan luar ruang" · `tunda_masuk` "Tunda jam masuk" · `pulang_awal` "Pulangkan lebih awal" · `daring` "Belajar daring".
- Env: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `FIRMS_MAP_KEY`, `CRON_SECRET`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME`, `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `NEXT_PUBLIC_APP_URL`, `DEMO_PASSWORD` (hanya untuk seed).
- Deadline 31 Oktober 2026 23:59 WIB. Hari 1 = 20 Okt.

## Review Focus

1. **Sumber data gagal atau kena rate limit saat refresh.** Forecast lama tetap disimpan, halaman menampilkan "Data belum diperbarui sejak HH:MM WIB", dan status tidak berubah jadi "normal" diam-diam. Dites di Task 4 (`refresh keeps previous forecasts when a source fails`) dan Task 5 (`isStale`).
2. **Notifikasi berulang tiap jam untuk level yang sama.** Kirim hanya saat level naik. Dites di Task 8 (`shouldNotify`).
3. **Absen dikirim dua kali untuk siswa yang sama di hari yang sama.** Data terakhir yang dipakai, tidak jadi dua baris. Dites di Task 9 (SQL `submit_checkin` upsert).
4. **Absen pagi WIB tercatat ke tanggal kemarin karena UTC** (06:30 WIB = 23:30 UTC hari sebelumnya). Dites di Task 9 (`todayWIB`).
5. **Mode darurat dinyalakan ulang tiap jam selama rekomendasi masih daring.** Hanya aktif kalau belum ada mode aktif. Dites di Task 8 (`shouldActivateEmergency`).

  - `ACTION_LABEL: Record<Action,string>`, `HAZARD_LABEL: Record<Hazard,string>` ("Asap karhutla", "Banjir / hujan ekstrem", "Angin / cuaca ekstrem"), `LEVEL_COLOR: Record<Level,string>` (`#2e7d32`, `#f9a825`, `#ef6c00`, `#c62828`)

Ambang (diputuskan, kutip di proposal):
- Asap, dari PM2.5 µg/m³ dengan breakpoint ISPU (PermenLHK P.14/2020): `<55.5 → 0`, `55.5–150.4 → 1`, `150.5–250.4 → 2`, `≥250.5 → 3`. Ditambah 1 (maksimal 3) kalau `upwindHotspots ≥ 10`.
- Banjir, dari curah hujan 24 jam (kategori BMKG): `<50 → 0`, `50–<100 → 1`, `100–<150 → 2`, `≥150 → 3`.
- Angin, dari hembusan km/jam: `<40 → 0`, `40–<62 → 1`, `62–<89 → 2`, `≥89 → 3`. weather_code `95` → minimal 1, `96`/`99` → minimal 2.
- Aksi: asap `1 kurangi_luar, 2 tunda_masuk, 3 daring` · banjir `1 kurangi_luar, 2 pulang_awal, 3 daring` · angin `1 kurangi_luar, 2 tunda_masuk, 3 daring` · level 0 → `normal`.
